# first_repository
# code based adventure game
## this is my first project in python the goal was to explore the coding language and the use of AI within the coding space. I wanted to make a randomized adventure game that is different balanced and fun everytime the user plays.
## features in this include multiple different mobs, both hostile and non hostile, the player can encounter at varying health points. depleting hunger and health with food that can be collected to counter act the depleting hunger. randomized run ins with mobs, chests, with vaying items to collect such as gold coins shovels swords pickaxes and a bow and arrows, and villagers to make trades for such items in exchange for the gold coins that have been collected
future goals are to add armor and armor points to counter act hostile mobs attacks. add randomization to the mob's attacks. less health for the player but also adding multiple ways to gain that health back including keeping ur hunger over 90 adding 1 health each time an action is exicuted
